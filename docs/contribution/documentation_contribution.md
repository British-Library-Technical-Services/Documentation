# Documentation Contribution

This page outlines how to start contributing to this documentation site.

## 1. Getting Started

1. Create a [Github](https://github.com/) account
2. Request Contributor access to the [Documentation](https://github.com/British-Library-Technical-Services/Documentation) repo
3. Install a text editor with Markdown support, such as [VS Code](https://code.visualstudio.com/), or create a [Github Codepace](https://github.com/codespaces) 
4. Learn basic [Markdown syntax](https://www.markdownguide.org/cheat-sheet/)
